# S3 and MinIO source plugin

Install only when needed: `pip install 'docpipe-sdk[s3]'`. The base package and curated profiles do not include Boto3. Select the plugin with an `s3://bucket/key` URI; the request may include `"source_plugin": {"provider": "s3", "options": {}}`.

The process operator must configure S3's security boundary through `DOCPIPE_SOURCE_PLUGIN_OPTIONS`, a JSON map keyed by provider. For example:

```json
{"s3":{"allowed_buckets":["reports"],"allowed_prefixes":["published/"],"temporary_root":"/var/lib/docpipe/source-artifacts","region_name":"us-east-1","access_key_id_ref":{"kind":"environment","name":"DOCPIPE_S3_ACCESS_KEY"},"secret_access_key_ref":{"kind":"environment","name":"DOCPIPE_S3_SECRET_KEY"}}}
```

Create the temporary directory with private permissions (`0700`) before starting Docpipe. Export the referenced environment variables in the application process. Credential references are resolved only after S3 is selected; without them, the AWS default/workload credential chain is used. Raw credential option values are rejected. Requests cannot replace operator S3 settings, including bucket/prefix allowlists, endpoints, secrets, timeouts, or the temporary directory.

For MinIO or another compatible service, add `"endpoint_url":"https://minio.example:9000"`. Plain HTTP requires explicit `"allow_insecure_http":true` and should be limited to a trusted local network. Endpoint URLs cannot contain embedded credentials, paths, queries, or fragments. Set `region_name` as required by your service. The [local S3-compatible example](../../examples/s3-minio/README.md) uses SeaweedFS and throwaway credentials. CI also uses SeaweedFS for its service-backed S3 checks; MinIO-specific interoperability is not currently tested by this repository.

The resolver checks bucket and prefix policy before network access, HEADs the object for its declared size and version hint, then streams a conditional GET to compute SHA-256. The ETag or version ID is an opaque version hint, not assumed to be a content digest. Content is not held in memory or saved locally during resolution. A parser that needs a path triggers a second, bounded GET into a private temporary file; its digest must match the resolved object. The handle deletes that artifact when its operation ends, including failures. `max_bytes`, `chunk_bytes`, `connect_timeout`, `read_timeout`, and `total_timeout` are configurable operator limits.

S3-compatible implementations differ in versioning and conditional-request behavior. If an endpoint does not honor `If-Match` or version-pinned GETs, the digest check still protects materialized content; streaming readers should be tested against that endpoint's consistency guarantees.
